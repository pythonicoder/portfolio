# Personal Portfolio Website

Welcome to my personal portfolio website, where I showcase my projects, technical skills, education, and achievements as a Computer and Software Engineering student.

🌐 **Live Website:** https://sinankasikci.com


## Technologies Used

* React
* JavaScript
* HTML5
* CSS3
* Git & GitHub

## Features

* Responsive and modern user interface
* Project showcase section
* Downloadable CV
* Skills and education overview
* Contact information

## Run Locally

```bash
git clone https://github.com/pythonicoder/portfolio.git
cd portfolio
npm install
npm start
```
